## What's new

- Opening a build shows a panel that compares the build's result with its key frames side by side
- The asset list shows the progress of builds that are running
- New: choose how hard the model thinks
- Objects no longer sit separately in files; they all appear in the asset list
- A new game's first version appears on the node of the build that made it, instead of as a separate starting point
- A build's flow is named as soon as a chat hands work to it
- Fixed: imported character models face forward correctly, whichever way the model file points
- Fixed: pressing Done during a director build no longer starts new work
