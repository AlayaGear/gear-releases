## What's new

- Use your own video as a build target, with key frames taken at the seconds you choose; a video added on the home page goes to the game the idea becomes, and the idea's chat can see it too
- Videos in the input box show as cards, and as small tags once sent
- New: a free motion library that works offline with any character model; the toolbox has a free "Motion library" card for adding built-in motions to game characters
- Motion lists take character motions from the app's library first; standard builds list the motions and judge a run of frames for each one; 2D animation can pick objects from the list or use the game's own motions
- Lists: objects in a 3D game that share one image are marked "shared image", and each shows only its own part of it; objects in key frames are listed too, play key frames are judged on what actually plays, and drawing takes from the library first
- Gear Zero now updates itself from the public downloads page; updating Codex or Claude Code replaces the desktop app's copy, and failures are explained in the interface language
- Coin amounts use Gear Zero's own format, with a new coin badge; Extra High on the model button shows as xhigh
- Fixed: in macOS full screen, no gap is left for the traffic-light buttons beside the sidebar toggle; a video on the home page row is no longer lost after you type in it
