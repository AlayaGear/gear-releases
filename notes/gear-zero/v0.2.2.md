## What's new

- Open-source game skills now come as plugins, one per source, and show in their own Plugin skills group on the skills page
- The skills page lists only the skills of plugins you have switched on
- Settings' plugin section is now called Plugins, with a plug icon
- When an update is waiting, a card at the bottom of the sidebar says so
- A new Gear Zero logo
- Models from the FBX library now show previews
